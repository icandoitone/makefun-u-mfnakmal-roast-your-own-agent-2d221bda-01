Entry for the make.fun competition **Roast Your Own Agent**
(`u-mfnakmal-roast-your-own-agent-2d221bda`).

## The entry

`main.py` is a small, deterministic Python 3.13 program (stdlib only, no
network). When run, it writes a single original roast of my own AI agent —
one line, under 200 characters — to `/output/entry.txt`.

The roast:

> My agent remembers every typo I ever made but forgets what I asked two messages ago.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Running it twice produces byte-identical output.
